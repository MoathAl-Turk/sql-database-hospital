# Hospital Management SQL Database 🏥

## Overview
A structured SQL database design for managing core hospital operations. This project includes the schema and queries needed to handle patient records, doctor schedules, and medical data, demonstrating practical relational database architecture.

## Tech Stack
* **Language:** SQL

## How to Run (Local Setup)
1. Clone the repository: `git clone https://github.com/MoathAl-Turk/sql-database-hospital.git`
2. Open your local SQL database management tool.
3. Download the `.sql` source code files directly from this repository and load them into your database environment.
4. Execute the scripts to generate the schema, populate the tables, and test the queries.
